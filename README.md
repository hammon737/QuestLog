# QuestLog
Midterm Store
CITA255_Assignment1 Assignment 3- Midterm Store
Assignment 4: Live Data
How to run it: 
Open the .sln in Visual Studio, set the target to Windows Machine, press F5. 
What it does:
The program keeps track of the user's quests, who gave them, and what they're getting in return. The user can input however many quests they like and can delete them once they're finished.It also saves the user's previous progress for when they open it again.
